# Family Wall

Plan familiar de 30 días: movimiento, piel, niños, inglés, comidas y compras, casas, finanzas y más.

Abre `index.html` en el navegador o usa la página de GitHub Pages del repositorio.

Fuera de Claude, los datos se guardan solo en el navegador de cada dispositivo (no se sincronizan) y la lectura automática de fotos de entrenamientos no está disponible; se pueden anotar a mano.
